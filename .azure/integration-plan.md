# Integration Handoff

This project is frontend-only. No integration work is required for backend, database, authentication, migrations, or seed data.

## Frontend

- Folder: repository root
- Build: `npm run build`
- Dev: `npm run dev`
- API seam: none; event details are local typed constants in `src/App.tsx`
- Mock files to delete: none

## API Routes

- None

## Database

- None. Do not create migrations or seed data.

## Services

- Frontend (Essential): React, Vite, TypeScript, Fluent UI v9
